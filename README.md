# Uplift Probe website

Static site. No build step. Works on GitHub Pages as is.

## Put it online
1. Create a new public repository on github.com (for example `uplift-probe`).
2. Open the repository, choose "Add file" then "Upload files".
3. Drag in everything inside this folder (not the folder itself), then commit.
4. Go to Settings, then Pages. Under "Branch" pick `main` and `/ (root)`, then save.
5. After a minute or two the site is live at `https://YOUR-USERNAME.github.io/uplift-probe/`.

## Where things are
- Pages: the `.html` files in this folder
- Colours and fonts: `assets/css/style.css` (colours are at the top)
- Images: `assets/img/`
